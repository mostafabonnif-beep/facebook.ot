# FB → YouTube Uploader

أداة سطح مكتب (Windows/Linux) بواجهة عربية تسحب **ريلز/فيديوهات صفحات فيسبوك** وتنزّلها ثم ترفعها تلقائياً إلى **قناة YouTube** عبر YouTube Data API v3.

- الملف الذي يجب تشغيله: **`fb_youtube_uploader_v34.py`**
- نسخ سابقة محفوظة: `fb_youtube_uploader_v33.py`, `fb_youtube_uploader_v32_fixed.py`, `original_1.py`

> ⚠️ استخدم الأداة فقط مع محتوى تملك حق نشره. لا تخزّن كلمات مرور فيسبوك في البرنامج، واحتفظ بملفات `client_secrets.json` ورموز `*_token.json` و`cookies.txt` في مكان خاص.

## ما الجديد في v3.4 (استخراج + عناوين + برمجة مقطع + إخفاء المصدر)

| # | التحسين | التفصيل |
|---|---|---|
| 1 | **استخراج أذكى** | محددات دقيقة `a[href*="/reel/"]` بدل كل الروابط، توحيد رابط الصفحة (`/name` → `/name/reels`, `profile.php?id=X` → `+sk=reels_tab`)، كشف جدار تسجيل الدخول بدل الصمت، ومعالجة `StaleElement`. |
| 2 | **كوكيز في المتصفح** | حقن `cookies.txt` (Netscape أو JSON تصدير Cookie-Editor) في جلسة Selenium لرؤية كل الريلز بدل أول صفحة فقط. |
| 3 | **عناوين نظيفة** | حذف روابط وضجيج فيسبوك (مشاهدات/تفاعلات/متابعين)، قصّ عند حدود كلمة (لا ينشطر منتصف كلمة)، حد 100 حرف. |
| 4 | **إخفاء اسم الصفحة المصدر** | يُحذف اسم الصفحة من **العنوان والوصف** بكل أشكاله (حالة مختلفة/بلا مسافات)، ويُحذف المنشن من الوصف — لا يظهر مصدر المقطع أبداً في المنتج المنشور. |
| 5 | **فحص المقطع (ffprobe)** | يتحقق من وجود مسار فيديو ومدة صالحة وحجم معقول، ويرفض المقاطع المعطوبة/الجزئية قبل الرفع — يمنع رفع مقطع «فاضي». |
| 6 | **تغليف احترافي (ffmpeg)** | `faststart` لتسريع معالجة YouTube + **حذف كل البيانات الوصفية المسرّبة** (اسم الصفحة/المحرر/البرنامج) من ملف MP4 نفسه — بلا إعادة ترميز (نقل التدفقات). |
| 7 | **خيارات واجهة جديدة** | «إخفاء هوية المصدر» و«فحص وتحسين المقطع» قابلان للتفعيل من تبويب الخيارات، وتُحفظ تلقائياً في `ui_settings.json`. |

### متطلبات v3.4 الإضافية
- **ffmpeg/ffprobe** (اختياري لكن موصى به): على Windows نزّله من [ffmpeg.org](https://ffmpeg.org) وأضفه إلى PATH. بدونه تعمل الأداة كما كانت (تخطى الفحص/التغليف بأمان).

## التشغيل على Windows

ضع الملفات في مجلد واحد، افتح موجه الأوامر داخل المجلد ثم:

```bat
py -m pip install -r requirements.txt
copy config.ini.example config.ini
py fb_youtube_uploader_v34.py
```

عدّل `config.ini` إذا كان `client_secrets.json` أو مجلد الفيديو في مسار آخر. جرّب Reel واحداً أولاً قبل وضع قائمة كبيرة.

## التشغيل على Linux

```bash
python3 -m pip install -r requirements.txt
cp config.ini.example config.ini
python3 fb_youtube_uploader_v34.py
```

يتطلب متصفح Chrome/Chromium و `chromedriver` متوافقاً معه.

## تشغيل الاختبارات

```bash
python3 -m pip install -r requirements-dev.txt
python3 -m pytest -q
```

على Windows: شغّل `run_tests.bat`. الاختبارات لا تتصل بفيسبوك أو YouTube ولا تفتح نافذة رسومية.

## خطوات الاستخدام

1. تبويب **📄 الصفحات**: أضف رابط صفحة فيسبوك، وحدد عدد التمريرات وحد الفيديوهات (أو استوردها من CSV).
2. تبويب **📺 يوتيوب**: اختر الحساب النشط، الخصوصية، الوسوم، والوصف الإضافي.
3. تبويب **⚙️ خيارات متقدمة**: فعّل/أطفئ Headless، حذف الملف بعد الرفع، تنظيف الهاشتاجات، البدء بالأحدث، وملف الكوكيز، واضبط الجدولة.
4. تبويب **👤 الحسابات**: أضف أسماء القنوات؛ يُنشأ لكل قناة رمز `اسم_الحساب_token.json` عند أول ربط.
5. اضغط **▶ ابدأ العمل**. كل الرسائل تظهر في تبويب **📋 السجل**، والإحصاءات في **📊 لوحة التحكم**.

## عند ظهور عطل

افتح تبويب **السجل**، ثم الملف `errors.log` بجانب البرنامج. أرسل آخر 20 سطراً مع رابط Reel واحد. رسائل الأخطاء الآن حقيقية (ملف ناتج مفقود، خطأ تفويض، رفض من YouTube...) بدل التوقف الصامت.

## ملاحظات فنية

- **سلامة الخيوط:** لا يُعدَّل أي عنصر Tkinter من خيط العمل؛ كل شيء يمر عبر طابورين آمنين، والإعدادات تُقرأ قبل بدء الخيط.
- **كشف التكرار:** تُحفظ معرّفات الفيديو في `uploaded_ids.txt` (استيراد ذرّي بـ `fsync`).
- **ملفات محلية لا تُرفع للمستودع:** `config.ini`, `client_secrets.json`, `cookies.txt`, `*_token.json`, `accounts.json`, `uploaded_ids.txt`, `stats.json`, `ui_settings.json`, `errors.log`, `videos/` (انظر `.gitignore`).

## خارطة الطريق المقترحة

- استبدال Selenium بـ yt-dlp في مرحلة الاستكشاف لتقليل التعطّل.
- إعادة محاولة الفيديوهات الفاشلة فقط من تقرير الجلسة.
- قوالب عنوان/وصف، صور مصغرة، ورفع لقوائم تشغيل.
- تصدير تقرير CSV/Excel لكل جلسة.
