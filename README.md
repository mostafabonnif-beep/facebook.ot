# FB → YouTube Uploader v4.9 PRO — Merged Hardened

نسخة **مدموجة** تجمع مزايا خط `v4.x PRO` (ذكاء اصطناعي، مراقبة مستمرة، حصص، شعار، Telegram)
مع كل تحصينات خط `v3.6` (رفع موثوق، إخفاء المصدر، معالجة المقطع، إصلاح الأزرار).

**الملف الذي يجب تشغيله: `fb_youtube_uploader_v49_pro.py`**

---

## ما دُمج في v4.9

### من خط التحصين (v3.6 → v4.9)
| # | التحصين | الأثر |
|---|---|---|
| 1 | **تصنيف أخطاء YouTube** (`classify_upload_error`) | يميّز **نفاد الحصة اليومية** (يوقف) من **تحديد المعدل المؤقت 429** (يُعيد) من **الصلاحيات** (يوقف فوراً). سابقاً كان 429 يوقف كل العملية — سبب رئيسي لظهور الرفع «عشوائياً». |
| 2 | **تراجع أسّي مع رجّة** | 8 → 24 → 72 ثانية (حد 300) بدل فاصل ثابت. |
| 3 | **استئناف الرفع المنقطع** | يستأنف من آخر بايت مرفوع (حتى 5 مرات) بدل إعادة الملف من الصفر. |
| 4 | **التحقق بعد الرفع** (`verify_upload`) | يكشف الفيديو الذي بقي `private` بسبب مشروع Google غير مُدقّق، ويتحقق من قبول وقت الجدولة. |
| 5 | **عزل قائمة التشغيل** | فشل الإضافة لقائمة تشغيل كان يعيد رفع الفيديو كاملاً → الآن خطوة معزولة. |
| 6 | **إخفاء اسم الصفحة المصدر** | يُحذف الاسم من العنوان والوصف (ومن `uploader/channel` الذي يرجعه yt-dlp) — لا يظهر المصدر في العنوان أو الوصف أو البيانات الوصفية. |
| 7 | **تنظيف المقطع** (`finalize_video`) | faststart + **حذف كل البيانات الوصفية المسرّبة** بلا إعادة ترميز. |
| 8 | **فحص سلامة المقطع** (`validate_media`) | يرفض التالف (بلا مسار فيديو/مدة صفرية) بمنطق متساهل: إن فشل الفحص نفسه لا يرفض. |
| 9 | **عنوان أنظف** | إزالة روابط وضجيج الإحصاءات (views/reactions/تفاعل…) وفواصل زائدة، وإبقاء `#` و`&`، وحد 100 حرف. |
| 10 | **توحيد رابط الريلز** | `facebook.com/name` → `/name/reels`، و`profile.php?id=X` يُضاف له `sk=reels_tab`. |
| 11 | **ترتيب حتمي** | إزالة التكرار مع خيار «الأحدث أولاً» (كان `set` يخلط الترتيب). |
| 12 | **إيقاف فوري للتنزيل** | `progress_hook` يقطع التنزيل الجاري، مع تنظيف ملفات `.part`/`.ytdl`. |
| 13 | **أمان المسارات** | تنقية اسم الحساب قبل استخدامه في اسم ملف التوكن. |

### إصلاح الواجهة (خلل الأزرار المخفية)
كان حجم النافذة مثبّتاً **1100×880**، فأي شاشة أقصر من 880px (لابتوبات 768) تُخفي شريط
**البدء/الإيقاف خارج الشاشة** — مُثبت بالقياس: على 1024×768 كان الزر عند y=863 والشاشة 768
(`winfo_ismapped=False`). الآن يُحسب الحجم من أبعاد الشاشة فعلياً مع `minsize`، والأزرار
**ظاهرة على 1024×768 و1366×768 و1920×1080**.

## التشغيل

```bat
py -m pip install -r requirements.txt
copy config.ini.example config.ini
py fb_youtube_uploader_v49_pro.py
```

**افحص بيئتك أولاً:**
```bat
py doctor.py
```

**على سيرفر Linux:**
```bash
nohup python3 fb_youtube_uploader_v49_pro.py --cli > watch.log 2>&1 &
```

## تنبيهات
- ⚠️ **ملفات سرية لا تشاركها ولا ترفعها:** `config.ini`, `client_secrets.json`, `*_token.json`, `cookies.txt`, `ai_keys.json`, `state.json`, `history.jsonl`.
- استخدم فقط المحتوى الذي تملك حق نشره.
- حصة يوتيوب الافتراضية ≈ 10,000 وحدة/يوم ≈ **6 فيديوهات**؛ مع حسابين تتضاعف.
- الفيديوهات المرفوعة عبر مشروع Google **غير مُدقّق** قد تُقفل `private` (البرنامج ينبّهك الآن).
